Budgetella's frosted-glass surface — the base container for almost every card in-app.

```jsx
<GlassCard><h3>Annual summary</h3></GlassCard>
<GlassCard elevated radius="large">…</GlassCard>
```

`elevated` swaps translucent glass for a solid elevated surface. `radius`: small · row · medium (default) · large · sheet.
